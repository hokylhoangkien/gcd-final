# G6 image-only CLIP geometry on Stanford Cars

This exploratory comparison reuses G1 queries, bank and common pairs. Frozen OpenAI CLIP ViT-B/16 receives only RGB center crops and uses CLIP RGB normalization. The same bicubic 256-to-224 center crop geometry as DINO keeps image content aligned. CLIP runs once for both checkpoints. No categories, prompts, taxonomy or text embeddings enter the model or scoring rules.

D1 denotes fine-tuned DINOv1. D1Frozen is the pretrained DINOv1 control. D2 denotes frozen DINOv2. Each fusion equally averages the indicated cosine matrices. CLIPRisk uses the CLIP alternative-minus-current slot margin. Disagreement uses one minus top-10 Jaccard similarity between D1 and CLIP. Both risk-only rules retrieve with D1.

Flags target global coverage of 10%, 20% and 40%, rounded down with query-ID tie breaking. Subgroup metrics use the same global flags. Recovery and regression compare top-1 destinations on wrong sources against D1. Stable errors at 150 use G4's two-checkpoint definition, with label-blind bank matching of slots and bank-only semantic alignment.
